# game-design-club-website

how the website currently works

from the root directory you can find `/user/[id]` which represents some user's username which will take you to a user page. 
The plan is to have a similar thing for teams and a way for people to access this for each other. 


The website for the game design club

This website uses [Sveltekit](https://svelte.dev/docs/kit/introduction) as the framework 

To run use:
```
    npm run dev
```
> [!WARNING]
> This needs vite to run and if you don't have vite installed try running
```
    npm install
```
