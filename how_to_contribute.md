# How To Contribute 
Hello, this is just a small file laying out how to contribute to this repo, on a case by case basis. 

## Creating Issues
If you are creating an issue please write as detailed of an issue as possible and don't be afraid to create comment threads from issues.

## Resolving Issues 
If you are resolving an issue please create a branch of the format `#-description` where the `#` will be the number of the issue you are working on followed by a description of the problem you're fixing. 
an example of a good name branch for something like updating the homepage would be `15-updated-homepage`. 

When you are finished with an issue make a pull request and the repo owner will review it. If it does not pass review they will write a reason as to why. 

## Emergencies
If anything got pushed that wasn't expected (API-Keys) (DataBase URL) let the repo owner know ASAP so issues can be resolved.
